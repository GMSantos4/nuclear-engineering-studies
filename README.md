Personal study notes on nuclear engineering: reactor fundamentals, nuclear safety, regulation, and the commissioning of nuclear power plants.

The repository started as preparation for a master's application, and is now a general knowledge base. The notes are written to be **replicable**: clear enough that I can come back years later and understand them without the original sources at hand.

## How the notes are written

- **Language:** English.
- **One file per subject**, named in `snake_case` (e.g. `reactor_physics.md`).
- **Every file starts** with its scope and main references, followed by a table of contents.
- **Section numbers of the original document** are kept in headings when summarizing a standard (e.g. `## 1.4 Stages of commissioning (2.17 - 2.22)`), so it is easy to go back to the source.
- **"📝 Summing Up"** sections close long chapters with the key ideas.
- **Review questions** at the end of a file help with active recall.
- **Sources** are listed at the end of each file.

---

## Adding a new note

1. Create a `.md` file named after the subject.
2. Follow the structure above: scope → contents → notes → summing up → questions → sources.
3. Add a row to the **Contents** table in this README.

As the repository grows, files can be grouped into folders by topic (e.g. `fundamentals/`, `safety/`, `commissioning/`, `regulation/`).
